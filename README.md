# NetLab Suite | Сети и телекоммуникации

> Интерактивная виртуальная среда для проведения лабораторных и практических занятий по курсу «Сети и телекоммуникации» в виде современного веб-приложения.

---

## 🌟 Основные возможности

### 1. Каталог лабораторных работ
- **Организация по модели OSI**: Физический, Канальный, Сетевой, Транспортный и Прикладной уровни.
- **Поиск и фильтрация**: мгновенный фильтр по ключевым словам, номерам работ и уровням сети.
- **Учёт прогресса студента**: персонализация имени, отслеживание выполненных работ с сохранением в `localStorage`.

### 2. Лабораторная работа №1: Модуляция (AM, DSB, SSB) и цифровые манипуляции (ASK, FSK, PSK)
Полноценный схемотехнический EDA-конструктор для сборки радиопередающих и приемных трактов:
- **Палитра блоков (Каталог)**:
  - 🔊 **Источник сообщения (НЧ / Данные)**: синусоидальный тон, двухтональная речь, видеосигнал с синхроимпульсом, **цифровой поток битов** с настройкой последовательности (`10110010`) и скорости передачи $R_b$;
  - 📡 **Несущая (ВЧ)**: высокочастотное гармоническое несущее колебание $F_c$;
  - ⚡ **Модулятор / Манипулятор**:
    - **Аналоговая модуляция**: DSB-FC (классическая АМ), DSB-SC (балансная), SSB-USB (верхняя боковая), SSB-LSB (нижняя боковая);
    - **Цифровая манипуляция**: **ASK** (амплитудная / OOK), **FSK** (частотная 2-FSK с регулировкой девиации $\Delta F$), **PSK** (фазовая BPSK со скачками фазы на $180^\circ$);
  - 🎯 **Полосовой фильтр (Канал связи)**: регулировка ширины полосы $\Delta F$ и шума канала (AWGN);
  - 📈 **Виртуальный Осциллограф**: отображает сигнал во временной области $s(t)$ с переключаемой разверткой (1 ms, 2 ms, 4 ms) для детального наблюдения битов;
  - 📊 **Спектрограф / Анализатор спектра**: спектральные линии несущей, боковых полос AM/SSB, пиков $f_0/f_1$ в FSK и лепестков $R_b$ в ASK/PSK в реальном времени с учетом фильтрации;
  - 📻 **Приемник / Детектор**: детектирование огибающей, частоты и фазы с реальным аудиовоспроизведением через **Web Audio API**.
- **Типовые пресеты схем**:
  - ⚡ АМ (DSB-FC)
  - ⚡ SSB (Однополосная)
  - ⚡ АМн (ASK манипуляция)
  - ⚡ ЧМн (FSK манипуляция)
  - ⚡ ФМн (PSK манипуляция)
- **Методический блок**:
  - Вкладка **Теоретические основы** с физическими формулами, спектральными соотношениями и сравнительной таблицей всех видов модуляции/манипуляции;
  - Вкладка **Задания и контроль** с 6 практическими заданиями и самоконтролем ответов;
  - Вкладка **Отчет студента** с автоматической фиксацией параметров аналоговой и цифровой модуляции и экспортом в PDF / печать.

## 🛠️ Стек технологий и архитектура

- **Ядро**: Vanilla JavaScript (ES Modules) — максимальная легковесность, мгновенная реакция и нулевой overhead фреймворков.
- **Стилизация**: Модульный Vanilla CSS с поддержкой Custom Properties (дизайн-токены), глубокая темная HSL-палитра, Glassmorphism (`backdrop-filter: blur`), адаптивная верстка.
- **Сборщик и Dev-сервер**: [Vite](https://vitejs.dev/) — сверхбыстрый HMR и сборка продакшн-бандла за доли секунды.
- **Графика и звук**: HTML5 Canvas (высокая частота кадров 60 FPS для осциллограмм и спектра) + Web Audio API.

## 🚀 Инструкция по запуску

### Системные требования
- [Node.js](https://nodejs.org/) версии **18.0.0** или новее;
- Менеджер пакетов **npm** (поставляется вместе с Node.js).

### 1. Клонирование или открытие репозитория
Откройте терминал в папке проекта:
```bash
cd networks-lab-suite
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск dev-сервера для разработки
```bash
npm run dev
```

После запуска в консоли появится адрес локального сервера:
```
  VITE v8.3.4  ready in 275 ms

  ➜  Local:   http://localhost:5173/
```
Откройте [http://localhost:5173](http://localhost:5173) в браузере. Изменения в коде применяются мгновенно благодаря Hot Module Replacement (HMR).

## 📦 Сборка для продакшна

Для создания оптимизированного минифицированного статического бандла выполните:

```bash
npm run build
```

Собранные файлы будут помещены в каталог `dist/`.

Для проверки работы собранного продакшн-бандла локально:
```bash
npm run preview
```
